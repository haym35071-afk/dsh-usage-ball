DSH 用量悬浮球
================

一个贴在 DeepSeek Harness 窗口里的小球，点开看今天/本月花了多少钱、用了多少 token。
费用按 DeepSeek 官方人民币价目表（含高峰/空闲时段）估算。

适合谁
------
用 DeepSeek Harness 桌面版、想随时知道花了多少钱的人。

环境要求
--------
- Windows 10 / 11
- 已安装 DeepSeek Harness 桌面版（小球要贴在它的窗口里）
- 系统自带 Windows PowerShell（不用另装 Node，脚本会自动找 DSH 自带的运行时）

安装
----
1. 双击 `DSH-Usage-Ball-Setup.exe`（或解压后双击 `安装.cmd`）
2. 安装完成后，桌面和开始菜单会有「DSH 用量悬浮球」
3. 双击图标即可运行；小球出现在 DSH 窗口右下角

卸载
----
1. 右键小球 →「退出悬浮窗」
2. 删除 `%LOCALAPPDATA%\DshUsageBall` 文件夹
3. 删除桌面 / 开始菜单的快捷方式
4. 如果开过自启，运行安装目录里的 `uninstall-autostart.cmd`

怎么用
------
- 小球：显示今日花费。点一下展开详情卡片
- 卡片：今日花费 / token / 调用次数、近 7 天柱状图、本月和累计
- 收回：点卡片右上 `●`
- 平移：在小球或卡片上任意位置按住拖动（位置会记住）
- 缩放：鼠标靠近卡片四边或四角，指针变成双向箭头后拖动（0.8×–1.8×）
- 刷新：`↻`；右键小球有「立即刷新」「退出悬浮窗」

数据从哪来
----------
只读本机会话日志 `%USERPROFILE%\.dsh\sessions`，不联网、不上传。
费用口径与 DeepSeek 官方价目表一致：
- 缓存命中 0.02/0.04 元（空闲/高峰，每百万 tokens）
- 缓存未命中 1/2 元
- 输出 4/8 元
高峰为北京时间周一至周五 09:00-12:00、14:00-18:00（不含法定节假日）。

注意
----
- 这是估算，不是账单；以 DeepSeek 控制台为准
- 只统计本机日志；换机器、网页版、其他客户端的用量不在这里
- 会话标题生成、上下文压缩等内部调用如果没有写进日志 usage，就不会被计入

常见问题
--------
Q: 小球不出现？
A: 先确认 DeepSeek Harness 桌面版在运行；小球要贴在它的窗口里，DSH 最小化时会一起隐藏。

Q: 双击没反应 / 一闪而过？
A: 右键「DSH 用量悬浮球」→ 打开文件所在位置，双击 `start.cmd`（带控制台）看报错；也可以看 `%LOCALAPPDATA%\DshUsageBall\widget.log`。

Q: 想开机自动出现？
A: 运行安装目录里的 `install-autostart.cmd`。

Q: 数据会传出去吗？
A: 不会。脚本只读本地日志，只写自己安装目录里的 state.json / pos.json / widget.log。
